# DropFlow name and logo

The **code** of DropFlow is free software under the GNU GPL v3 or later (see `LICENSE`). The GPL covers the code only: the name
**"DropFlow"**, the DropFlow logo and the website domain are not licensed by it.

You may, without asking:
- say that your software is "based on DropFlow", "a fork of DropFlow" or "compatible with DropFlow";
- use the name and logo to talk about the official project (articles, videos, talks, links to the official downloads);
- build and use unmodified official releases inside your organisation.

Please ask first (open an issue) before:
- publishing a modified version under the name "DropFlow" or with the DropFlow logo. Forks must choose another name and logo, so users always know which build is the official one;
- using the name or logo in a product name, domain name, app-store listing or advertisement.
