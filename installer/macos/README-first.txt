DropFlow for macOS
==================

1. Drag DropFlow into the Applications folder.
2. The first time, open it with a right-click (or Control-click) on DropFlow in Applications, then choose "Open" and confirm.
   DropFlow is free and open source and is not notarized by Apple, so macOS asks once.
   If macOS only offers "Move to Trash": open System Settings > Privacy & Security, scroll down and click "Open Anyway" next to DropFlow.
3. DropFlow lives in the menu bar (top right). Drag a file in Finder and, while still holding the mouse button, tap
   Shift (convert), Command (tools) or Control (actions). Drop the file on a slice of the wheel.

No permission (Accessibility, Input Monitoring) is needed. Everything happens on this Mac; nothing is uploaded.
Source code and help: https://github.com/hamwimoustafa88-maker/dropflow


DropFlow لنظام macOS
====================

١. اسحب DropFlow إلى مجلد «التطبيقات».
٢. في المرة الأولى افتحه بالنقر بزر الفأرة الأيمن (أو Control مع النقر) على DropFlow في «التطبيقات»، ثم اختر «فتح» وأكّد.
   ‏DropFlow مجاني ومفتوح المصدر وغير موثَّق من Apple، لذلك يسألك macOS مرة واحدة.
   إذا لم يعرض macOS إلا «نقل إلى سلة المهملات»: افتح إعدادات النظام ← الخصوصية والأمان، ثم انزل واضغط «فتح على أي حال» بجانب DropFlow.
٣. يعمل DropFlow من شريط القوائم أعلى يمين الشاشة. اسحب ملفاً في Finder، وأثناء الضغط على زر الفأرة انقر
   Shift (للتحويل) أو Command (للأدوات) أو Control (للإجراءات)، ثم أفلت الملف على إحدى شرائح العجلة.

لا يحتاج DropFlow أي إذن خاص (تسهيلات الاستخدام أو مراقبة الإدخال). كل شيء يجري على هذا الحاسوب ولا يُرفع أي ملف.
الشيفرة المصدرية والمساعدة: https://github.com/hamwimoustafa88-maker/dropflow
